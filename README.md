# Sales Prediction Using Python

## Project Overview
This project predicts sales using Python and Machine Learning. It analyzes advertising spend, impressions, clicks, advertising platforms, and target segments.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## Project Steps
1. Dataset creation
2. Data cleaning
3. Data preprocessing
4. Feature selection
5. Train-test splitting
6. Linear Regression model training
7. Sales prediction
8. Model evaluation
9. Data visualization
10. Business insights

## Files Included
- `Sales_Prediction_Using_Python.ipynb` – Project notebook
- `sales_prediction_dataset.csv` – Dataset

## Conclusion
This project demonstrates a basic sales prediction workflow using Linear Regression and explores the relationship between advertising data and sales.
